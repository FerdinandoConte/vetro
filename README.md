# Vetro

**Your Android tablet as a real extended monitor for your Windows PC — native resolution, up to 120 Hz, touch and pen, over USB or Wi-Fi, with measured latency.**

> Status: **pre-alpha, milestone M0** (baseline and feasibility). Nothing to install yet.

## Why
Existing options cap at 60 Hz, compress heavily, need developer options for USB, or are built for game streaming rather than for being a monitor. Vetro aims to be a plug-in-and-it-is-a-screen experience, open source, with every latency claim backed by a reproducible measurement.

## Targets
| Link | Glass-to-glass p50 | p99 |
|---|---|---|
| USB | ≤ 20 ms | ≤ 40 ms |
| Wi-Fi 5/6 GHz | ≤ 30 ms | ≤ 80 ms |
