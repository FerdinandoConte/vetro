# M1 — MVP: Windows desktop extended to an Android tablet

**Goal:** a signed, installable release where the tablet becomes an extended monitor over Wi-Fi and USB tethering, at the M0 target mode, with touch and pen, paired by QR code, and latency published from HIL runs.

Build as a **tracer bullet**: get a synthetic frame from the engine to the tablet's screen end to end first (M1-1…M1-6), then swap in the real pieces (M1-7…M1-10), then the product surface (M1-11…M1-16).

## Exit criteria
- [ ] Real desktop on the tablet's virtual monitor over Wi-Fi and over USB tethering (if available per M0).
- [ ] Up to 120 fps while content moves; 0 encoded frames while the screen is still (telemetry proves it).
- [ ] Multi-touch and pen with pressure/tilt/hover work in Paint, OneNote and Krita (manual checklist).
- [ ] QR pairing; unpaired devices rejected at the TLS handshake (test).
- [ ] mDNS discovery on Wi-Fi.
- [ ] HUD shows per-stage latency; HIL report meets the SLOs of ADR-0012 or documents the gap with a plan.
- [ ] 30-minute soak at the target mode without throttling-induced SLO breach.
- [ ] Signed installer (engine + tray + VDD + FFmpeg DLLs) and signed APK on a GitHub pre-release.
- [ ] README with measured numbers, install guide, known limitations.
- [ ] Manual checklist `docs/manual-tests/m1.md` executed; ChatGPT review packet answered and triaged.
