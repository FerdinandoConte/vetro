# M2 — USB zero-config (AOA)

**Goal:** plug the cable and the tablet becomes a monitor: no developer options, no toggles, the app opens by itself.

Detailed work items are written by the lead at the start of M2 from ADR-0016 (the M0 AOA spike). Expected shape:

| ID | Title | Agent |
|---|---|---|
| M2-1 | Host USB layer: detect the tablet, send AOA start requests, open bulk endpoints (driver path per ADR-0016) | core-engineer |
| M2-2 | `quinn` socket adapter over USB bulk (framing, MTU, backpressure) | core-engineer |
| M2-3 | Android `UsbAccessory` handling, auto-launch intent filter, permission flow with "always" default | ui-engineer (accessory I/O by core-engineer) |
| M2-4 | Driver packaging and signing in the installer | ui-engineer |
| M2-5 | HIL over AOA; latency comparison with tethering | core-engineer |

## Exit criteria
- [ ] Fresh tablet with developer options off: plug in → app opens → monitor appears within 3 s.
- [ ] Same mutual TLS as other transports.
- [ ] HIL p50/p99 over AOA no worse than over tethering.
- [ ] Installer handles the driver without manual steps beyond the install-time UAC prompt.
