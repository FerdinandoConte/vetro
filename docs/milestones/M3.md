# M3 — Continuity (USB ↔ Wi-Fi failover)

**Goal:** unplugging or plugging the cable never ends the session.

Detailed work items are written by the lead at the start of M3. Expected shape:

| ID | Title | Agent |
|---|---|---|
| M3-1 | Keep both paths warm; path health probing | core-engineer |
| M3-2 | QUIC connection migration across AOA and Wi-Fi socket adapters | core-engineer |
| M3-3 | Keyframe and bitrate reset on switch; FEC re-tune | core-engineer |
| M3-4 | UI indicator of the active path | ui-engineer |
| M3-5 | HIL scripted unplug/replug (or interface disable) with glitch measurement | core-engineer |

## Exit criteria
- [ ] Cable unplug → Wi-Fi within 300 ms, no session loss, windows stay on the virtual monitor.
- [ ] Cable replug → back on USB automatically.
- [ ] Glitch duration measured and published.
